# Canvas 文件助手

在已登录的 Canvas 课程页面点击插件，打开独立文件库页面。点击「扫描全部 Modules」，然后按文件格式、章节或关键词筛选，勾选文件并批量下载。

## 加载

1. 打开 Chrome 的扩展程序管理页面 `chrome://extensions`。
2. 打开「开发者模式」，选择「加载已解压的扩展程序」。
3. 选择本目录（包含 manifest.json 的 canvas-module-files 文件夹）。
4. 在 Canvas 课程页面，通过工具栏扩展程序菜单点击「Canvas 文件助手」。

## 范围与行为

- 动态读取当前课程全部 Modules，每个章节的条目和所有分页。章节数量、名称、周数、课程 ID 和学校域名均不写死。
- 提取直接 File 条目、Page 正文及其同课程关联 Page 中的文件、作业/讨论/测验说明中的附件，以及明确的外部文件直链。遇到循环页面链接会去重。
- 页面中仅作为图片展示的校徽、横幅、导航图标和插图不收进文件清单。图片有明确附件链接、download 下载链接或本身是 Module 的 File 条目时仍会保留。嵌入 PDF 等文档继续识别，普通网页、播放器与流媒体清单不算文件直链。
- 外部直链文件从课程附件主列表中分离，放在独立的折叠区域，默认不勾选。主列表「全选课程附件」不包含外部直链，必须在外部区域逐项勾选或使用单独的「全选外部直链」后，才会加入批量下载。外部选择每次打开页面或重新扫描时重置，不记为默认偏好。
- 按真实文件名和 MIME 分类：PDF、PPT、Word、Excel、视频、音频、压缩包、图片、PSIM、文本、XML、代码与数据、其他。未知扩展名仍保留。
- 使用 `locked_for_user` 判断文件是否被锁定。`hidden_for_user` 只表示文件列表中的可见性，不单独作为禁止下载的条件。文件信息读取失败时保留课程来源链接，并显示「可尝试下载」，不冒充已验证可下载。
- 优先使用 Canvas 返回的下载 URL；原页面下载链接中的授权参数也会保留。下载由 Chrome 执行，使用其已有的登录会话，不向 IDM 等工具传递账号、密码或 Cookie。
- 按 Canvas 文件 ID 去重，文件列表只显示一行，记录全部章节和来源页面。下载时可选择「仅保存一份（首次来源）」或「每个来源目录各保存一份」。后者按照启用的章节/页面目录创建副本，同一个目标路径不重复创建任务。
- 外部文件直链合并锚点、跟踪参数、常见预览/下载标志和参数顺序造成的重复；保留文件身份、版本和授权参数。不按文件名强行合并不同文件。同章同一来源页面只记录一次，忽略 module_item_id 导航参数和锚点。
- 勾选下载最多同时运行 3 个任务；完成后自动继续队列。实际完成、失败状态来自 Chrome 的下载记录。失败后可重新勾选下载。
- 提供最近一批的总进度和每份文件的进度，显示接收/写入字节、完成份数和暂停/停止/失败状态。服务器未提供文件大小时显示“大小未知”，不会假定字节百分比。默认下载模式每秒刷新 Chrome 的进度。
- 可以暂停、继续或停止单份文件，也可以控制当前课程的全部未完成任务。暂停包含等待中的任务；停止后队列不会自动启动后续任务，已完成文件保留。停止后需要重新勾选发起新任务。默认模式的继续能力由 Chrome 和文件服务器决定。
- 下载时可勾选「按 Module 创建文件夹」和「保留来源页面目录」（默认开启，并记住上次选择）。完整结构为 Chrome 下载目录内的 `Canvas/课程名/Module 名/来源页面标题/文件分类/原文件名`，例如 `Canvas/课程/Week 1/Week 1 - Lectorial/PDF/讲义.pdf`。两项均可独立关闭，页面会显示当前目录结构。同名冲突由 Chrome 自动编号，不覆盖已有文件。
- 文件夹选项仅影响新加入的下载任务，已在队列中的任务继续使用加入时的目录结构。章节和页面目录都关闭时，共享文件只保存一份。
- 下载时向 Chrome 指定相对路径，并在文件名确定事件中再次指定本插件任务的目录，不修改其他下载。下载记录会显示计划路径和 Chrome 返回的实际绝对路径；完成时若保存目录不符，会提示并支持打开所在文件夹。其他扩展或用户手动改变保存位置时，不能把网络下载成功当成目录功能已生效。
- 页面左上角显示版本。更新扩展后请关闭旧的文件助手页面，从课程重新打开。旧页面发出的下载请求会明确提示版本不一致。

## 选择本地保存位置

选择“逐个文件下载”时默认使用 Chrome 下载目录。点击下载区的「选择本地文件夹…」，在系统选择器中选择并允许写入目标文件夹后，新的下载改由插件直接写入该目录，并继续使用 Module、来源页面、格式和共享副本选项。点击「改用 Chrome 默认目录」可以切回原方式，不改变已经开始的任务。

自选目录模式首次下载会按所选文件的来源网站申请可选读取权限，只请求实际选中文件的来源域名。通过浏览器现有登录会话读取文件，不使用 IDM，不导出账号密码或 Cookie。没有授权、返回登录网页或读取失败时显示错误，不会悄悄改存到默认目录。

自选目录模式必须保持文件助手页面打开，目标文件夹每次打开助手页后重新选择，不在后台记住文件夹授权。该模式的进度表示实际写入字节；暂停会停止继续读取和写入，少量在途数据可能暂存在浏览器缓冲中。停止会终止请求并清理本次新建的未完成文件，已完成文件保留。同名文件自动编号，不覆盖已有文件。

浏览器不向网页公开所选文件夹的完整系统路径，因此自选目录模式显示“所选文件夹名/实际子目录/文件名”；默认模式仍显示 Chrome 返回的绝对路径。部分跨站下载若无法通过已授予的来源权限读取，可切回 Chrome 默认下载方式。
- 章节读取失败、权限失败和锁定页面显示在问题列表；不会将有读取错误的扫描标为完整。
- 外部播放器、LTI 和普通网页单独列出，不将网页入口当成视频文件。外部平台提供的登录、下载能力由原网站决定。

## 使用提示

保持 Canvas 已登录。扫描期间请保持课程标签页和文件助手页打开。课程标签页改变课程或关闭后，请在目标课程重新点击插件图标。

若 Chrome 设置为每次下载均询问保存位置，批量下载仍可能出现保存对话框；该设置由用户控制。

## 权限与数据

基础权限为 activeTab、scripting、storage 和 downloads。点击插件后才在当前课程页读取数据。自选目录下载另使用可选网站权限，仅在点击下载时请求所选来源域名，不会直接申请所有网站的访问权限。目标文件夹由用户通过系统选择器授权。不读取密码或自行复制登录 Cookie，不发送课程清单到第三方服务器。默认模式的清单与队列保存在本机扩展存储；自选目录模式的任务记录仅保留在当前助手页面，页面关闭后不自动续传。

ZIP 使用随插件附带的 fflate 0.8.3（MIT 许可，见 vendor/），运行时不加载远程脚本。扫描使用 Canvas 官方 Modules、Pages、Files 等接口，下载使用 Chrome downloads 接口。

参考：[Canvas Modules](https://canvas.instructure.com/doc/api/modules.html)、[Canvas Pages](https://canvas.instructure.com/doc/api/pages.html)、[Canvas Files](https://canvas.instructure.com/doc/api/files.html)、[Chrome downloads](https://developer.chrome.com/docs/extensions/reference/api/downloads)。


## 界面、ZIP 与空间占用

- 桌面右侧“准备下载”面板集中显示保存位置、下载方式、目录结构和下载按钮；窄窗口自动移到列表上方。重复来源折叠展开查看，外部直链保持独立且需要额外勾选。
- 默认选择“打包为一个 ZIP”，也可切换“逐个文件下载”。ZIP 内按现有 Module、来源页面、文件格式和共享副本选项整理，附带“文件来源清单.json”，记录全部章节与页面来源。ZIP 用存储模式打包，优先避免额外 CPU 开销，大小不一定缩小。
- ZIP 默认模式完成后只向 Chrome 提交一个 ZIP，并弹出保存位置选择窗口；若已选择本地文件夹，直接在该文件夹写入一个 ZIP，不逐个创建 Chrome 下载记录。同名文件和压缩包自动编号。
- ZIP 完全在插件内处理，只向原文件来源读取内容，不上传文件到打包服务器，不依赖独立后端、本地服务、IDM 或运行时 CDN。首次打包按所选来源申请读取权限；单个文件返回 HTTP 错误、登录网页或在传输中断开时，跳过该文件，继续处理后续内容。ZIP 内附“下载失败清单.json”，记录文件名、章节、来源页面和失败原因；“文件来源清单.json”也注明每个目标是否成功。全部文件失败时不生成空 ZIP。用户停止或压缩包无法写入时，中止并清理未完成压缩包。
- 收集与打包支持总进度、暂停、继续、停止，必须保持文件助手页打开。当前 ZIP 单包最大 4 GB，最多 65533 个附件，超过请分批勾选。
- 默认 ZIP 优先流式写入浏览器专用临时空间，Chrome 完成保存或取消后立即删除临时 ZIP，并释放下载地址。为避免传输失败留下残缺 ZIP 条目，每次只暂存一个文件，接收完整后再写入 ZIP，随后立即删除该文件的临时副本。浏览器不支持临时文件系统时才使用内存暂存；直接选择本地文件夹时 ZIP 写入目标位置，单文件暂存仍使用浏览器临时空间。意外关闭助手页留下的临时文件，在超过 24 小时后的下一次打开/清理时自动清除。
- 持久化只保留清单、选项和任务元数据，不缓存 PDF 等附件正文。课程清单最多 3 门、合计 2 MiB，超过 30 天未更新自动清除；新扫描仍可在当前页使用。已结束下载记录最多保留 100 条，并移除其下载 URL；进行中/暂停任务不因清理上限被丢弃。
- 页面底部显示清单和记录的占用量，提供“清理本地数据”，清除课程清单与已结束任务记录，保留下载选项和进行中任务，不删除已下载文件，也不清除 Chrome 自身的下载历史。

ZIP 实现参考：[fflate 官方说明](https://github.com/101arrowz/fflate)。


## 中英界面

顶部语言菜单可切换中文与 English，并记住上次选择。按钮、筛选、计数、下载状态、诊断提示、搜索和无障碍标签均随界面语言更新；课程名、Module、来源页面标题和文件名保留原文。语言包在本机按需读取，不调用翻译服务。

本地化独立为 `i18n.js` 与 `locales/`，共 282 个翻译条目。新增语言只需添加 JSON 语言包并登记 `locales/languages.json`，具体步骤见 [LOCALIZATION.md](LOCALIZATION.md)。


## 原生下载控制修复（版本保持 1.0.0）

Chrome 默认目录的逐个文件下载中，暂停/停止优先控制已有任务，不再等待另一个文件的启动请求返回。下载创建和文件名确定事件会尽早关联任务编号；尚未返回编号的任务也保留控制意图，在编号返回后立即处理，后续排队文件不会继续启动。

暂停、继续、停止后读取 Chrome 实际状态；操作失败会在页面状态栏和对应文件行明确显示，不将失败当作成功。控制限定于当前课程与对应任务，不控制其他课程或非本插件任务。进度刷新在按下文件行控制按钮期间延后，避免按钮在点击完成前被移除。

修改后请在 Chrome 中重新加载插件，关闭旧助手页，从课程重新打开。Chrome 下载列表仍会保留暂停/取消的记录，记录存在不表示任务仍在传输。

进度条下方按钮明确标记“暂停全部 / 继续全部 / 停止全部”，作用于当前课程全部未完成任务；文件行内按钮只控制对应的一份文件，其他任务可以继续。


## ZIP 跳过失败文件与进度修复（版本保持 1.0.0）

收集文件、写入 ZIP 和保存 ZIP 分别显示当前阶段。进度按已处理文件数和当前文件读取/写入进度更新，不再因为部分文件大小未知而一直停在 0。无法确定大小时显示动态活动条和已处理数量，不假定当前文件的字节百分比；最终 ZIP 保存成功后才到 100%。ZIP 进度更新不再反复重建整张文件表。

失败文件在进度区单独列出，完成时明确显示成功与跳过数量。下载失败文件不以空文件或残缺文件混进压缩包。所有处理仍在插件内部进行，无独立后端。

ZIP 名称使用 `课程名_资料_YYYY-MM-DD_HH-mm-ss.zip`（英文界面为 `Course name_Files_YYYY-MM-DD_HH-mm-ss.zip`），按本地时间生成。Chrome 的保存窗口和自选文件夹使用相同名称；临时文件的随机编号不会作为最终下载名称。Chrome 保存前会在浏览器会话存储中暂存名称与下载地址的对应关系，保存或取消后删除，不持久写入课程缓存。

## 失败恢复与后台生命周期

最近一批下载结束后，“仅重试失败项”沿用原保存位置和目录结构；共享文件只补失败的来源副本。整个 ZIP 最终无法写入/保存时，按钮改为“重新打包未保存的 ZIP”，重新包含全部原选文件，避免遗漏已收集但未保存的内容。原生任务重试使用当前清单刷新下载链接；清单过期需重新扫描。

ZIP/自选目录采用 45 秒网络闲置超时、最多 2 次自动重试。临时网络异常和 HTTP 408/429/5xx 可重试，401/403 与磁盘错误不自动重试。暂停冻结网络计时；停止中断请求和重试等待。原生 Chrome 下载的网络恢复由 Chrome 管理，插件保存任务编号及控制意图，后台恢复后核对浏览器实际状态，无法确认启动的任务会显示失败而不重复提交。

超过 2 MiB 缓存上限的扫描仍能从当前助手页直接启动下载；本机缓存上限不变。长时间暂停的 ZIP 持有浏览器锁，其他助手页清理旧临时文件时会跳过它。已结束批次的计划在清理本地数据时释放。
